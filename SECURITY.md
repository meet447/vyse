# Security

## Reporting a vulnerability

If you believe you have found a security issue in Vyse, please report it responsibly.

**Preferred:** open a [GitHub Security Advisory](https://github.com/meet447/vyse/security/advisories/new) (private) if you have access, or contact a maintainer through GitHub with details kept confidential.

**Otherwise:** open a [GitHub issue](https://github.com/meet447/vyse/issues/new) describing the problem **without** a public proof-of-concept or exploit steps until maintainers have had time to respond.

There is no dedicated security email for this repository yet.

## Scope

Reports should cover the open-source code in this repository (`vyse-cli`, `vyse-edge`, `vyse-core`). Infrastructure and credentials for the hosted edge at `vyse.chipling.xyz` are operated separately and are out of scope for this tracker.

## Supported versions

Security fixes are applied on the default branch and released in the next tagged version. Use [GitHub Releases](https://github.com/meet447/vyse/releases) for up-to-date binaries.
